# Fuel Dispatch Management System


Operational fuel request and dispatch management application developed with AppSheet.

## Features

* Fuel request registration
* Approval and rejection workflows
* Dispatch validation
* Requisition tracking
* Automatic gallon consolidation
* Mobile-first operational interface
* Relational database structure
* Role-based access

## Technologies

* AppSheet
* Database backend
* No-Code Development

## My Responsibilities

* Process analysis
* Workflow design
* Database structure
* App development
* Client communication
* UI/UX adjustments
* Operational troubleshooting
